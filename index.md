# Welcome

This site collects notes and examples on practical data science, machine
learning, and AI. Use the navigation to explore the topics.

## Content provenance

- New AI-generated or substantially AI-rewritten study material is marked with
  an `!!! info "AI-generated"` admonition.
- Markers appear directly below the most specific section heading that contains
  the generated content.
- On mixed-origin pages and notebooks, markers identify only the affected
  content; source datasets and generated site output are not marked.
