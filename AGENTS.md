# Repository Instructions

## AI content provenance

- Mark every new AI-generated or substantially AI-rewritten study-content addition under `book/` with the MkDocs admonition `!!! info "AI-generated"`.
- Put the marker immediately after the narrowest section or subsection heading that contains the AI-generated material.
- Do not place an AI marker directly below the page title or use one marker for an entire page. If AI generated introductory prose, create a specific `Overview`, `Purpose`, or `Scope` section and mark that section.
- On a mixed-origin page, mark only the affected paragraph, code block, section, or subsection. Add a short scope note when nearby legacy material remains unchanged.
- For notebook content, add the marker in the relevant Markdown cell; do not label source datasets or generated build output.
- Keep existing provenance markers when content is moved, merged, renamed, or reorganized. Move or revise the marker so its scope remains accurate.
- Use the same `AI-generated` metadata convention for generated diagrams and other study artifacts.
- Update `README.md` and `book/index.md` whenever the provenance convention changes.
